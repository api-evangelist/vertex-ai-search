Vertex AI Search is Google Cloud’s enterprise search solution that leverages generative AI to enable organizations to index, search, and retrieve information across structured and unstructured data sources. It integrates with Vertex AI, BigQuery, and other Google Cloud services to provide semantic search, relevance tuning, and secure access controls, helping businesses unlock insights from their data at scale.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Vertex AI Search: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
